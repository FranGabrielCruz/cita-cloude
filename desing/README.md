# Referencias de diseño de CitaCloud

Esta carpeta conserva las decisiones visuales que deben mantenerse al implementar las pantallas Vaadin.

- Interfaz SaaS limpia, clara y responsive.
- Navegación lateral dentro del layout principal.
- Acciones primarias mediante iconos con tooltip.
- Montos con dos decimales y fechas en formato `DD/MM/YYYY`.
- Colores expresados mediante variables Lumo para mantener compatibilidad con modo oscuro.
- Tablas con altura basada en sus filas y paginación visible.

Las especificaciones particulares se documentan en archivos separados por módulo.
