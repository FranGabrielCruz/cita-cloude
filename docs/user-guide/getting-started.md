# Primeros pasos

Este manual está dirigido al personal autorizado de clínicas.

## Iniciar sesión

**Requisitos:** código de empresa, usuario y contraseña activos.

1. Abra Cita Cloud.
2. Ingrese Empresa, Usuario y Contraseña.
3. Presione Iniciar sesión.

**Resultado:** se muestra el Dashboard y únicamente los módulos permitidos. Si la sesión expiró, inicie nuevamente. No comparta su contraseña.

## Navegación

El menú agrupa Dashboard, Gestión clínica, Administración, Operación clínica, Gestión financiera/operativa y Gestión y Control. Las opciones disponibles dependen de su rol. Use los filtros y la paginación; las acciones de icono muestran su nombre al colocar el cursor.

Continúe con [Operación clínica](clinical.md), [Operación financiera](financial.md) o [Administración](administration.md).
