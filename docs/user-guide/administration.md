# Manual administrativo

## Usuarios y roles

**Requisitos:** permisos administrativos.

1. Cree o edite el usuario dentro de su empresa.
2. Asigne un rol vigente.
3. En Roles seleccione solo los módulos y acciones necesarios.
4. Active/desactive según corresponda y guarde.

No asigne acceso sensible por conveniencia. Los cambios no permiten administrar datos de otra empresa.

## Configuración de notificaciones

1. Abra Configuración y localice Notificaciones de citas.
2. Edite el asunto y el mensaje del correo.
3. Active el canal cuando el administrador técnico haya configurado SMTP.
4. Realice una prueba con un destinatario ficticio/autorizado.

El usuario, la contraseña y la dirección `no-reply` de SMTP son datos técnicos y no aparecen en esta pantalla. WhatsApp está temporalmente retirado de la configuración funcional.

## Cajas y secuencias fiscales

Configure cajas por sucursal, asigne usuarios y active las disponibles. En secuencias fiscales registre tipo, nombre, prefijo, desde, hasta y siguiente según la autorización real. No reutilice números ni altere una secuencia consumida sin procedimiento autorizado.

## Auditoría

Use filtros para identificar eventos y abra detalles solo cuando su permiso lo permita. Auditoría muestra acciones de usuarios; para un fallo técnico entregue el `requestId` a soporte.
