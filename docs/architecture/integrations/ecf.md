# Integración e-CF

**Estado:** BORRADOR / INFRAESTRUCTURA PARCIAL

Actualmente existen pantalla, estado e-CF y secuencias de comprobante fiscal internas, pero no se documenta como completa una conexión certificada con DGII o proveedor autorizado.

Para habilitarla deben definirse proveedor/interfaz oficial, certificados y firma, ambientes, numeración autorizada, envío, trackId, consulta de estado, aceptación/rechazo, representación impresa, contingencia, anulaciones, idempotencia, webhooks, observabilidad y almacenamiento de XML. Las credenciales y certificados se mantienen fuera de Git.
